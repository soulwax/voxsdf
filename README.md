# voxsdf

Pure Dart 3D Signed Distance Field CSG sculpting engine: analytic primitives (`SdfSphere`, `SdfBox`, `SdfCapsule`, `SdfTorus`), smooth union/subtract/intersect brushes, trilinear voxel grids, sphere-tracing raymarcher, and dual Surface Nets triangle extraction.
